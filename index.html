CSS Measurements

This page shows common CSS units, size constraints, and responsive values. Resize the browser to compare.

Measurements

Pixels (px)

A pixel is an absolute unit in CSS. Its size does not depend on the parent element or viewport.

width: 200px

Percent (%)

A percentage is usually based on the size of the parent element.

width: 50%

em

em is relative to font-size. when used on fonts, it is based on the parent's font-size. when used on padding and margin, it is based on it's own font-size.

16px text

1em

32px text

2em

rem

rem is based on the root (html) font-size. It is commonly used for consistent font sizes and spacing.

The browsers default font-size is 16px. This can be changed for people who have trouble seeing, perhaps they make it larger.

font-size: 3rem

characters (ch)

ch is spproximately the width of the "0" character. It is useful for controlling the readable line of text.

Lorem ipsum dolor sit amet consectetur adipisicing elit. Repellendus amet sit numquam cupiditate corporis reiciendis fugiat, neque eligendi hic at!

vw (viewport-width)

vw is based on the browser width. 1vw is 1% of the viewport's width. Unline %, it is not based on the parent element.

width: 50vw

vh (viewport-height)

vh is based on the brower height. 1vh is 1% of the viewport's height.

height: 30vh
